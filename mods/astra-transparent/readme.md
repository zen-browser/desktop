# Astra Transparent Mode (legacy — unused at runtime)

Transparent Mode is built into Astra Browser.

- Preference: `astra.theme.transparent.enabled`
- Stylesheet: `chrome://browser/content/zen-styles/astra-transparent-mode.css`
- Manager: `chrome://browser/content/zen-components/AstraTransparencyManager.mjs`

This directory is historical documentation only. It is not registered, downloaded,
or loaded by the browser. Existing profile entries named `astra-transparent`
are migrated once and removed.
