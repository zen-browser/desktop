# Support Response Templates

## Missing Version

Please add the exact Nevai Browser Desktop version and artifact filename. Do not use "latest" because alpha builds change quickly.

## Missing Reproduction Steps

Please add numbered steps that reproduce the issue from a clean launch. Include what you expected and what actually happened.

## Platform Not Supported Yet

That platform is not part of the currently published alpha artifacts. We will track it in the roadmap, but this issue cannot be treated as a release blocker until the platform has an artifact.

## Possible Upstream Issue

Please check whether the same behavior reproduces in upstream Firefox. If it does, note the Firefox version and attach the result. That helps separate Nevai-specific regressions from upstream browser behavior.

## Needs Logs

Please attach the relevant runtime or terminal logs. If this is a startup issue, include the full launch output from the terminal.

## Security Issue

Please do not post security details publicly. Use the private security advisory flow:

https://github.com/ali-ezz/nevai-browser-desktop/security/advisories/new
