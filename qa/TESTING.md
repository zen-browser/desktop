# Testing Checklist

## Build

- npm i: pass/fail
- npm run init: pass/fail
- language pack update: pass/fail
- npm run build: pass/fail
- npm start: pass/fail

## Rebrand Check

- App opens
- App name changed
- Main icon changed
- About page checked
- Settings page checked
- No obvious Zen branding in normal UI

## Smoke Test

- Open google.com
- Open youtube.com
- Open github.com
- Download a file
- Open private window
- Open settings
- Create workspace
- Close/reopen browser
