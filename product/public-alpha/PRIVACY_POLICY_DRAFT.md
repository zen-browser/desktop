# Nevai Browser Privacy Policy Draft

This is a working draft for alpha planning. It is not final legal text.

## Product

Nevai Browser Desktop is an alpha desktop browser.

## Alpha Data Policy

For alpha builds:

- automatic updates are disabled
- no Nevai account system is included
- no Nevai sync service is included
- crash reporting is not enabled unless explicitly documented in the release notes
- telemetry decisions must be documented before public release

## Local Browser Data

The browser may store local data such as:

- browsing history
- cookies and site data
- bookmarks
- downloads metadata
- settings
- extension data
- local profiles

This data is stored on the user's device unless a feature explicitly sends it elsewhere.

## Third-Party Services

Browser features may contact third-party services inherited from upstream browser code or selected defaults. Before public alpha, this section must list active external services and their purpose.

## Updates

Alpha automatic updates are disabled. Users must install new alpha builds manually.

## Security Reports

Security reports should use the repository security advisory flow:

https://github.com/ali-ezz/nevai-browser-desktop/security/advisories/new

## Before Public Alpha

This draft must be reviewed and completed before public distribution.
