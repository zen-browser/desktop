### Contributing

If you'd like to report a bug, please do so on our [GitHub Issues page](https://github.com/Hrishikeshmind/astradesktop/issues/) and for feature requests, you can use [Github Discussions](https://github.com/Hrishikeshmind/astradesktop/discussions).

Astra is an open-source project, and we welcome contributions from the community! Please take a look at the [contribution guidelines](./docs/contribute.md) before getting started!
