# License Attribution Checklist

This checklist must be completed before any public alpha release.

## Repository

- `LICENSE` file is present.
- upstream license notices are preserved.
- modified-source obligations are understood.
- public source availability path is documented.

## Product Text

- release notes mention upstream open-source basis.
- README does not imply false affiliation.
- About dialog wording is reviewed.
- download page includes source/license link.

## Third-Party Components

- Mozilla/Firefox notices are preserved where required.
- Zen Browser upstream attribution is preserved where required.
- bundled dependencies retain license files where required.
- generated packages do not strip required notices.

## Release Artifacts

- artifact README includes license/source statement.
- checksums are published.
- source tag or commit is recorded.

## Open Questions

- final public source URL
- final attribution text
- final website legal pages
- whether separate NOTICE file is needed
